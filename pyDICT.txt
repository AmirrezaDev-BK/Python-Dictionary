Python Glossary / واژه‌نامه پایتون
===================================

This dictionary contains ALL Python terms with definitions in both English and Persian.
این دیکشنری شامل تمام اصطلاحات پایتون با تعاریف به دو زبان انگلیسی و فارسی است.

═══════════════════════════════════════════════════════════════════════════════

ALL BUILT-IN FUNCTIONS / تمام توابع داخلی
═══════════════════════════════════════════════════════════════════════════════

abs
   English: Returns the absolute value of a number.
   فارسی: مقدار مطلق یک عدد را برمی‌گرداند.

all
   English: Checks if all elements in an iterable are True.
   فارسی: بررسی می‌کند که آیا همه عناصر یک iterable True هستند.

any
   English: Checks if at least one element in an iterable is True.
   فارسی: بررسی می‌کند که آیا حداقل یک عنصر در iterable True است.

ascii
   English: Returns an ASCII representation of an object.
   فارسی: نمایش ASCII از یک شیء را برمی‌گرداند.

bin
   English: Converts an integer to a binary string.
   فارسی: یک عدد صحیح را به رشته دودویی تبدیل می‌کند.

bool
   English: Converts a value to a boolean (True/False).
   فارسی: یک مقدار را به بولین (True/False) تبدیل می‌کند.

breakpoint
   English: Drops into the debugger at the call site.
   فارسی: وارد دیباگر در محل فراخوانی می‌شود.

bytearray
   English: Creates a mutable bytearray object.
   فارسی: یک شیء bytearray قابل تغییر ایجاد می‌کند.

bytes
   English: Creates a bytes object from an iterable or string.
   فارسی: یک شیء bytes از یک iterable یا رشته ایجاد می‌کند.

callable
   English: Checks if an object is callable (can be called as a function).
   فارسی: بررسی می‌کند که آیا یک شیء قابل فراخوانی است.

chr
   English: Returns a character from a Unicode code point.
   فارسی: یک کاراکتر را از کد یونیکد برمی‌گرداند.

classmethod
   English: Converts a method to a class method.
   فارسی: یک متد را به متد کلاسی تبدیل می‌کند.

compile
   English: Compiles source code into a code object.
   فارسی: کد منبع را به یک شیء کد کامپایل می‌کند.

complex
   English: Creates a complex number from real and imaginary parts.
   فارسی: یک عدد مختلط از بخش حقیقی و موهومی ایجاد می‌کند.

delattr
   English: Deletes an attribute from an object.
   فارسی: یک ویژگی را از یک شیء حذف می‌کند.

dict
   English: Creates a dictionary object.
   فارسی: یک شیء دیکشنری ایجاد می‌کند.

dir
   English: Returns a list of attributes and methods of an object.
   فارسی: لیست ویژگی‌ها و متدهای یک شیء را برمی‌گرداند.

divmod
   English: Returns a tuple containing quotient and remainder of division.
   فارسی: یک تاپل شامل خارج‌قسمت و باقیمانده تقسیم را برمی‌گرداند.

enumerate
   English: Returns an enumerate object with index-value pairs.
   فارسی: یک شیء enumerate با جفت‌های ایندکس-مقدار برمی‌گرداند.

eval
   English: Evaluates a Python expression from a string.
   فارسی: یک عبارت پایتون را از یک رشته ارزیابی می‌کند.

exec
   English: Executes Python code dynamically from a string or object.
   فارسی: کد پایتون را به صورت پویا از رشته یا شیء اجرا می‌کند.

filter
   English: Filters items from an iterable using a function.
   فارسی: آیتم‌ها را از یک iterable با استفاده از یک تابع فیلتر می‌کند.

float
   English: Converts a value to a floating-point number.
   فارسی: یک مقدار را به عدد اعشاری تبدیل می‌کند.

format
   English: Formats a value using a format specification.
   فارسی: یک مقدار را با استفاده از مشخصات قالب‌بندی، قالب‌بندی می‌کند.

frozenset
   English: Creates an immutable frozenset object.
   فارسی: یک شیء frozenset غیرقابل تغییر ایجاد می‌کند.

getattr
   English: Gets the value of an attribute from an object.
   فارسی: مقدار یک ویژگی را از یک شیء دریافت می‌کند.

globals
   English: Returns the global symbol table as a dictionary.
   فارسی: جدول نمادهای سراسری را به صورت دیکشنری برمی‌گرداند.

hasattr
   English: Checks if an object has a specific attribute.
   فارسی: بررسی می‌کند که آیا یک شیء ویژگی خاصی دارد.

hash
   English: Returns the hash value of an object.
   فارسی: مقدار هش یک شیء را برمی‌گرداند.

help
   English: Invokes the built-in help system.
   فارسی: سیستم راهنمای داخلی را فراخوانی می‌کند.

hex
   English: Converts an integer to a hexadecimal string.
   فارسی: یک عدد صحیح را به رشته هگزادسیمال تبدیل می‌کند.

id
   English: Returns the identity (memory address) of an object.
   فارسی: شناسه (آدرس حافظه) یک شیء را برمی‌گرداند.

input
   English: Reads a line from standard input (keyboard).
   فارسی: یک خط از ورودی استاندارد (صفحه‌کلید) می‌خواند.

int
   English: Converts a value to an integer.
   فارسی: یک مقدار را به عدد صحیح تبدیل می‌کند.

isinstance
   English: Checks if an object is an instance of a class or tuple of classes.
   فارسی: بررسی می‌کند که آیا یک شیء نمونه‌ای از یک کلاس یا تاپل کلاس‌ها است.

issubclass
   English: Checks if a class is a subclass of another class.
   فارسی: بررسی می‌کند که آیا یک کلاس زیرکلاس کلاس دیگری است.

iter
   English: Returns an iterator object from an iterable.
   فارسی: یک شیء iterator از یک iterable برمی‌گرداند.

len
   English: Returns the length (number of items) of an object.
   فارسی: طول (تعداد آیتم‌ها) یک شیء را برمی‌گرداند.

list
   English: Creates a list object from an iterable.
   فارسی: یک شیء لیست از یک iterable ایجاد می‌کند.

locals
   English: Returns the local symbol table as a dictionary.
   فارسی: جدول نمادهای محلی را به صورت دیکشنری برمی‌گرداند.

map
   English: Applies a function to every item in an iterable.
   فارسی: یک تابع را به هر آیتم در یک iterable اعمال می‌کند.

max
   English: Returns the largest element in an iterable.
   فارسی: بزرگترین عنصر را در یک iterable برمی‌گرداند.

memoryview
   English: Creates a memoryview object from a bytes-like object.
   فارسی: یک شیء memoryview از یک شیء شبه‌بایت ایجاد می‌کند.

min
   English: Returns the smallest element in an iterable.
   فارسی: کوچکترین عنصر را در یک iterable برمی‌گرداند.

next
   English: Returns the next item from an iterator.
   فارسی: آیتم بعدی را از یک iterator برمی‌گرداند.

object
   English: Creates a new featureless object.
   فارسی: یک شیء جدید بدون ویژگی ایجاد می‌کند.

oct
   English: Converts an integer to an octal string.
   فارسی: یک عدد صحیح را به رشته هشتی تبدیل می‌کند.

open
   English: Opens a file and returns a file object.
   فارسی: یک فایل را باز می‌کند و یک شیء فایل برمی‌گرداند.

ord
   English: Returns the Unicode code point of a character.
   فارسی: کد یونیکد یک کاراکتر را برمی‌گرداند.

pow
   English: Returns the result of x raised to the power of y.
   فارسی: نتیجه x به توان y را برمی‌گرداند.

print
   English: Prints objects to the text output stream.
   فارسی: اشیاء را به خروجی متن چاپ می‌کند.

property
   English: Creates a property attribute.
   فارسی: یک ویژگی property ایجاد می‌کند.

range
   English: Creates a sequence of numbers from start to stop.
   فارسی: یک دنباله از اعداد از start تا stop ایجاد می‌کند.

repr
   English: Returns a string representation of an object.
   فارسی: یک نمایش رشته‌ای از یک شیء برمی‌گرداند.

reversed
   English: Returns a reversed iterator from a sequence.
   فارسی: یک iterator معکوس از یک دنباله برمی‌گرداند.

round
   English: Rounds a number to a specified precision.
   فارسی: یک عدد را به دقت مشخصی گرد می‌کند.

set
   English: Creates a set object from an iterable.
   فارسی: یک شیء مجموعه از یک iterable ایجاد می‌کند.

setattr
   English: Sets the value of an attribute on an object.
   فارسی: مقدار یک ویژگی را روی یک شیء تنظیم می‌کند.

slice
   English: Creates a slice object for slicing sequences.
   فارسی: یک شیء slice برای برش دنباله‌ها ایجاد می‌کند.

sorted
   English: Returns a sorted list from an iterable.
   فارسی: یک لیست مرتب شده از یک iterable برمی‌گرداند.

staticmethod
   English: Converts a method to a static method.
   فارسی: یک متد را به متد ایستا تبدیل می‌کند.

str
   English: Converts a value to a string.
   فارسی: یک مقدار را به رشته تبدیل می‌کند.

sum
   English: Sums all elements in an iterable.
   فارسی: همه عناصر را در یک iterable جمع می‌زند.

super
   English: Returns a proxy object for delegating method calls to a parent class.
   فارسی: یک شیء نماینده برای واگذاری فراخوانی‌های متد به کلاس والد برمی‌گرداند.

tuple
   English: Creates a tuple object from an iterable.
   فارسی: یک شیء تاپل از یک iterable ایجاد می‌کند.

type
   English: Returns the type of an object or creates a new type.
   فارسی: نوع یک شیء را برمی‌گرداند یا یک نوع جدید ایجاد می‌کند.

vars
   English: Returns the __dict__ attribute of a module, class, or object.
   فارسی: ویژگی __dict__ یک ماژول، کلاس، یا شیء را برمی‌گرداند.

zip
   English: Aggregates elements from multiple iterables into tuples.
   فارسی: عناصر را از چند iterable در تاپل‌ها جمع‌آوری می‌کند.

__import__
   English: Called by the import statement to load a module.
   فارسی: توسط دستور import برای بارگذاری یک ماژول فراخوانی می‌شود.

ALL BUILT-IN TYPES / تمام انواع داخلی
═══════════════════════════════════════════════════════════════════════════════

bool
   English: Boolean type - True or False values.
   فارسی: نوع بولین - مقادیر True یا False.

bytearray
   English: Mutable sequence of bytes (0-255).
   فارسی: دنباله قابل تغییر از بایت‌ها (۰-۲۵۵).

bytes
   English: Immutable sequence of bytes (0-255).
   فارسی: دنباله غیرقابل تغییر از بایت‌ها (۰-۲۵۵).

complex
   English: Complex number type with real and imaginary parts.
   فارسی: نوع عدد مختلط با بخش حقیقی و موهومی.

dict
   English: Dictionary type - key-value mapping.
   فارسی: نوع دیکشنری - نگاشت کلید-مقدار.

float
   English: Floating-point number type.
   فارسی: نوع عدد اعشاری.

frozenset
   English: Immutable set type.
   فارسی: نوع مجموعه غیرقابل تغییر.

int
   English: Integer number type.
   فارسی: نوع عدد صحیح.

list
   English: List type - mutable sequence.
   فارسی: نوع لیست - دنباله قابل تغییر.

memoryview
   English: Memory view type for buffer protocol.
   فارسی: نوع نمای حافظه برای پروتکل بافر.

NoneType
   English: Type of the None object.
   فارسی: نوع شیء None.

range
   English: Range type - immutable sequence of numbers.
   فارسی: نوع range - دنباله غیرقابل تغییر از اعداد.

set
   English: Set type - unordered collection of unique items.
   فارسی: نوع مجموعه - مجموعه نامرتب از آیتم‌های یکتا.

slice
   English: Slice type for slicing sequences.
   فارسی: نوع slice برای برش دنباله‌ها.

str
   English: String type - immutable sequence of characters.
   فارسی: نوع رشته - دنباله غیرقابل تغییر از کاراکترها.

tuple
   English: Tuple type - immutable sequence.
   فارسی: نوع تاپل - دنباله غیرقابل تغییر.

type
   English: The type of a type object.
   فارسی: نوع یک شیء نوع.

ALL KEYWORDS / تمام کلمات کلیدی
═══════════════════════════════════════════════════════════════════════════════

and
   English: Logical AND operator.
   فارسی: عملگر منطقی AND.

as
   English: Used to create an alias for a module or exception.
   فارسی: برای ایجاد نام مستعار برای ماژول یا استثنا استفاده می‌شود.

assert
   English: Assertion for debugging.
   فارسی: اظهار برای دیباگ.

async
   English: Defines an asynchronous function.
   فارسی: تابع غیرهمزمان تعریف می‌کند.

await
   English: Waits for an awaitable object to complete.
   فارسی: منتظر تکمیل یک شیء awaitable می‌ماند.

break
   English: Breaks out of a loop.
   فارسی: از یک حلقه خارج می‌شود.

case
   English: Used in pattern matching (match-case).
   فارسی: در تطبیق الگو استفاده می‌شود (match-case).

class
   English: Defines a new class.
   فارسی: یک کلاس جدید تعریف می‌کند.

continue
   English: Continues to the next iteration of a loop.
   فارسی: به تکرار بعدی حلقه ادامه می‌دهد.

def
   English: Defines a function.
   فارسی: یک تابع تعریف می‌کند.

del
   English: Deletes an object or element.
   فارسی: یک شیء یا عنصر را حذف می‌کند.

elif
   English: Else if condition.
   فارسی: شرط else if.

else
   English: Else condition.
   فارسی: شرط else.

except
   English: Catches an exception.
   فارسی: یک استثنا را می‌گیرد.

finally
   English: Always executes after try-except.
   فارسی: همیشه بعد از try-except اجرا می‌شود.

for
   English: For loop iteration.
   فارسی: حلقه for.

from
   English: Imports from a module.
   فارسی: از یک ماژول وارد می‌کند.

global
   English: Declares a global variable.
   فارسی: یک متغیر سراسری اعلام می‌کند.

if
   English: If condition.
   فارسی: شرط if.

import
   English: Imports a module.
   فارسی: یک ماژول را وارد می‌کند.

in
   English: Membership test or iterable traversal.
   فارسی: تست عضویت یا پیمایش iterable.

is
   English: Identity comparison operator.
   فارسی: عملگر مقایسه هویت.

lambda
   English: Creates an anonymous function.
   فارسی: یک تابع ناشناس ایجاد می‌کند.

match
   English: Pattern matching (match-case).
   فارسی: تطبیق الگو (match-case).

nonlocal
   English: Declares a variable from an enclosing scope.
   فارسی: یک متغیر از محدوده محصور را اعلام می‌کند.

not
   English: Logical NOT operator.
   فارسی: عملگر منطقی NOT.

or
   English: Logical OR operator.
   فارسی: عملگر منطقی OR.

pass
   English: Does nothing (placeholder).
   فارسی: هیچ کاری انجام نمی‌دهد (جای‌نگین).

raise
   English: Raises an exception.
   فارسی: یک استثنا را برمی‌انگیزد.

return
   English: Returns a value from a function.
   فارسی: یک مقدار را از یک تابع برمی‌گرداند.

try
   English: Tests code for exceptions.
   فارسی: کد را برای استثناها تست می‌کند.

while
   English: While loop.
   فارسی: حلقه while.

with
   English: Context manager statement.
   فارسی: دستور مدیریت زمینه.

yield
   English: Yields a value from a generator.
   فارسی: یک مقدار را از یک جنریتور تولید می‌کند.

ALL SPECIAL METHODS / تمام متدهای خاص
═══════════════════════════════════════════════════════════════════════════════

__abs__
   English: Called for abs() function.
   فارسی: برای تابع abs() فراخوانی می‌شود.

__add__
   English: Called for addition (+) operator.
   فارسی: برای عملگر جمع (+) فراخوانی می‌شود.

__aenter__
   English: Called at start of async with statement.
   فارسی: در شروع دستور async with فراخوانی می‌شود.

__aexit__
   English: Called at end of async with statement.
   فارسی: در پایان دستور async with فراخوانی می‌شود.

__aiter__
   English: Called to create an asynchronous iterator.
   فارسی: برای ایجاد یک iterator غیرهمزمان فراخوانی می‌شود.

__anext__
   English: Called to get next item from asynchronous iterator.
   فارسی: برای دریافت آیتم بعدی از iterator غیرهمزمان فراخوانی می‌شود.

__await__
   English: Called to make object awaitable.
   فارسی: برای awaitable کردن شیء فراخوانی می‌شود.

__call__
   English: Makes an object callable like a function.
   فارسی: یک شیء را مانند یک تابع قابل فراخوانی می‌کند.

__contains__
   English: Called for membership tests (in operator).
   فارسی: برای تست عضویت (عملگر in) فراخوانی می‌شود.

__del__
   English: Called when an object is about to be destroyed.
   فارسی: زمانی که یک شیء در حال نابودی است فراخوانی می‌شود.

__delattr__
   English: Called when deleting an attribute.
   فارسی: زمانی که یک ویژگی حذف می‌شود فراخوانی می‌شود.

__delete__
   English: Called when deleting a descriptor attribute.
   فارسی: زمانی که یک ویژگی descriptor حذف می‌شود فراخوانی می‌شود.

__delitem__
   English: Deletes an item from a container by index or key.
   فارسی: یک آیتم را از ظرف با ایندکس یا کلید حذف می‌کند.

__dir__
   English: Called for dir() function.
   فارسی: برای تابع dir() فراخوانی می‌شود.

__divmod__
   English: Called for divmod() function.
   فارسی: برای تابع divmod() فراخوانی می‌شود.

__enter__
   English: Enter method for context managers (with statement).
   فارسی: متد ورود برای مدیریت‌کننده‌های زمینه (دستور with).

__eq__
   English: Called for equality comparison (==).
   فارسی: برای مقایسه برابری (==) فراخوانی می‌شود.

__exit__
   English: Exit method for context managers (with statement).
   فارسی: متد خروج برای مدیریت‌کننده‌های زمینه (دستور with).

__format__
   English: Called for format() function.
   فارسی: برای تابع format() فراخوانی می‌شود.

__ge__
   English: Called for greater-or-equal comparison (>=).
   فارسی: برای مقایسه بزرگتر یا مساوی (>=) فراخوانی می‌شود.

__get__
   English: Called to get a descriptor attribute.
   فارسی: برای دریافت یک ویژگی descriptor فراخوانی می‌شود.

__getattr__
   English: Called when an attribute is not found.
   فارسی: زمانی که یک ویژگی پیدا نشود فراخوانی می‌شود.

__getattribute__
   English: Called for attribute access.
   فارسی: برای دسترسی به ویژگی فراخوانی می‌شود.

__getitem__
   English: Gets an item from a container by index or key.
   فارسی: یک آیتم را از ظرف با ایندکس یا کلید دریافت می‌کند.

__gt__
   English: Called for greater-than comparison (>).
   فارسی: برای مقایسه بزرگتر (>) فراخوانی می‌شود.

__hash__
   English: Called for hash() function.

   فارسی: توانایی ارجاع به متغیرها در یک تعریف محصور.

new-style class
   English: Class flavor used for all class objects in modern Python.
   فارسی: نوع کلاسی که برای همه اشیاء کلاس در پایتون مدرن استفاده می‌شود.

object
   English: Any data with state and defined behavior.
   فارسی: هر داده‌ای با وضعیت و رفتار تعریف شده.

optional module
   English: Extension module that may be absent in some Python builds.
   فارسی: ماژول افزونه که ممکن است در برخی ساخت‌های پایتون وجود نداشته باشد.

package
   English: Python module that can contain submodules or subpackages.
   فارسی: ماژول پایتون که می‌تواند شامل زیرماژول‌ها یا زیربسته‌ها باشد.

parallelism
   English: Executing multiple operations simultaneously on different cores.
   فارسی: اجرای همزمان چندین عملیات روی هسته‌های مختلف.

parameter
   English: Named entity in a function definition specifying an argument.
   فارسی: موجودیت نام‌دار در تعریف تابع که یک آرگومان را مشخص می‌کند.

path entry
   English: Single location on the import path.
   فارسی: یک مکان واحد در مسیر import.

path entry finder
   English: Finder that locates modules given a path entry.
   فارسی: Finder که ماژول‌ها را با توجه به یک path entry پیدا می‌کند.

path based finder
   English: Meta path finder that searches an import path.
   فارسی: Meta path finder که یک import path را جستجو می‌کند.

path-like object
   English: Object representing a file system path (str, bytes, PathLike).
   فارسی: شیء نمایش‌دهنده یک مسیر سیستم فایل (str، bytes، PathLike).

PEP
   English: Python Enhancement Proposal - design document for Python features.
   فارسی: پیشنهاد بهبود پایتون - سند طراحی برای ویژگی‌های پایتون.

portion
   English: Set of files in a directory contributing to a namespace package.
   فارسی: مجموعه فایل‌ها در یک دایرکتوری که به یک بسته فضای نام کمک می‌کنند.

positional argument
   English: Argument that is not a keyword argument.
   فارسی: آرگومانی که یک آرگومان کلیدی نیست.

provisional API
   English: API excluded from backwards compatibility guarantees.
   فارسی: API که از تضمین‌های سازگاری معکوس مستثنی شده است.

Python 3000
   English: Nickname for the Python 3.x release line (Py3k).
   فارسی: نام مستعار برای سری انتشارات پایتون ۳.x (Py3k).

Pythonic
   English: Code closely following common Python idioms.
   فارسی: کدی که از اصطلاحات رایج پایتون پیروی می‌کند.

qualified name
   English: Dotted name showing path from module's global scope to an object.
   فارسی: نام نقطه‌چین نشان‌دهنده مسیر از فضای سراسری ماژول به یک شیء.

race condition
   English: Behavior depending on relative timing of events.
   فارسی: رفتاری که به زمان‌بندی نسبی رویدادها بستگی دارد.

reference count
   English: Number of references to an object.
   فارسی: تعداد ارجاعات به یک شیء.

regular package
   English: Traditional package with an __init__.py file.
   فارسی: بسته سنتی با فایل __init__.py.

reentrant
   English: Function or lock that can be called/acquired multiple times by the same thread.
   فارسی: تابع یا قفلی که می‌تواند چندین بار توسط همان رشته فراخوانی/اختصاص داده شود.

REPL
   English: Read-Eval-Print Loop (interactive interpreter shell).
   فارسی: حلقه خواندن-ارزیابی-چاپ (شل مفسر تعاملی).

__slots__
   English: Declaration in a class that saves memory by pre-declaring instance attributes.
   فارسی: اعلامیه در یک کلاس که با پیش‌اعلام ویژگی‌های نمونه، حافظه را ذخیره می‌کند.

sequence
   English: Iterable supporting efficient element access by integer index.
   فارسی: Iterable که از دسترسی کارآمد به عناصر با ایندکس عدد صحیح پشتیبانی می‌کند.

set comprehension
   English: Compact way to process iterable and return a set.
   فارسی: روشی فشرده برای پردازش iterable و بازگرداندن یک مجموعه.

single dispatch
   English: Generic function dispatch based on the type of a single argument.
   فارسی: توزیع تابع عمومی بر اساس نوع یک آرگومان.

slice
   English: Object describing a portion of a sequence.
   فارسی: شیء توصیف‌کننده بخشی از یک دنباله.

special method
   English: Method implicitly called by Python for specific operations.
   فارسی: متدی که به طور ضمنی توسط پایتون برای عملیات خاص فراخوانی می‌شود.

standard library
   English: Collection of packages and modules distributed with Python.
   فارسی: مجموعه بسته‌ها و ماژول‌هایی که با پایتون توزیع می‌شوند.

statement
   English: Part of a suite (block of code) - expression or keyword construct.
   فارسی: بخشی از یک suite (بلوک کد) - عبارت یا ساختار کلیدی.

static type checker
   English: External tool analyzing code for type issues.
   فارسی: ابزار خارجی که کد را برای مشکلات نوع تحلیل می‌کند.

strong reference
   English: Reference where the code owns the object.
   فارسی: ارجاعی که کد مالک شیء است.

subscript
   English: Expression in square brackets of a subscription expression.
   فارسی: عبارت در کروشه‌های یک عبارت subscription.

synchronization primitive
   English: Basic building block for coordinating multiple threads.
   فارسی: بلوک سازنده اساسی برای هماهنگی چندین رشته.

text encoding
   English: Serialization of Unicode strings to bytes.
   فارسی: سریال‌سازی رشته‌های یونیکد به بایت.

text file
   English: File object able to read and write strings.
   فارسی: شیء فایل قادر به خواندن و نوشتن رشته‌ها.

thread state
   English: Information used by CPython to run in an OS thread.
   فارسی: اطلاعاتی که CPython برای اجرا در یک رشته سیستم‌عامل استفاده می‌کند.

thread-safe
   English: Code that behaves correctly when used by multiple threads concurrently.
   فارسی: کدی که وقتی توسط چندین رشته به طور همزمان استفاده می‌شود، به درستی رفتار می‌کند.

token
   English: Small unit of source code (name, number, operator, etc.).
   فارسی: واحد کوچکی از کد منبع (نام، عدد، عملگر و غیره).

triple-quoted string
   English: String bound by three quotation marks or apostrophes.
   فارسی: رشته‌ای که با سه علامت نقل‌قول یا آپستروف محدود شده است.

type
   English: Determines what kind of object an object is.
   فارسی: تعیین می‌کند که یک شیء چه نوع شیء است.

type alias
   English: Synonym for a type, created by assignment.
   فارسی: مترادفی برای یک نوع، که با انتساب ایجاد می‌شود.

type hint
   English: Annotation specifying expected type for a variable or function.
   فارسی: annotation که نوع مورد انتظار را برای یک متغیر یا تابع مشخص می‌کند.

universal newlines
   English: Interpreting \n, \r\n, and \r as line endings.
   فارسی: تفسیر \n، \r\n، و \r به عنوان پایان‌دهنده خط.

variable annotation
   English: Annotation of a variable or class attribute.
   فارسی: annotation یک متغیر یا ویژگی کلاس.

virtual environment
   English: Isolated runtime environment for Python packages.
   فارسی: محیط اجرایی ایزوله برای بسته‌های پایتون.

virtual machine
   English: Computer defined entirely in software.
   فارسی: کامپیوتری که کاملاً در نرم‌افزار تعریف شده است.

walrus operator
   English: Assignment expression operator (:=) that looks like a walrus.
   فارسی: عملگر عبارت انتساب (:=) که شبیه به شیر دریایی است.

Zen of Python
   English: Listing of Python design principles and philosophies.
   فارسی: فهرستی از اصول طراحی و فلسفه‌های پایتون.
